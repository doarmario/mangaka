# Integração Qi Scans

Cópia versionada do wrapper `mangaka-qiscans`; origem em [UPSTREAM.md](UPSTREAM.md).

O Compose do Mangaka constrói este diretório e disponibiliza a API em `http://qiscans:3002`, somente na rede interna. Os testes offline rodam durante o build.

Para atualizar esta cópia, execute `scripts/export.py` no repositório do wrapper e faça commit no Mangaka. Não execute a exportação a partir desta cópia.
